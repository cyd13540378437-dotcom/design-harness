# 深蓝紫科技

## 用户可见摘要

用深蓝与清晰紫色建立现代技术可信度，适合需要精密感的数字产品。

## 色彩气质

精密、现代、技术、流动。

## 适合的产品语义

- 支付科技
- 基础设施
- 开发平台
- 数据产品

## 不适合的产品语义

- 自然生活方式
- 儿童教育
- 传统文化内容

## 界面落地建议

深 Slate 负责文字与技术纵深，紫色负责行动，青色只做活跃信号。

主色与强调色需要按视觉优先级使用，不要把所有色阶平均铺开。

## 无障碍与可读性风险

风险等级：medium。

- 正式实现需检查正文、按钮、细线、标签和禁用态。
- 不得仅依靠颜色表达状态或优先级。

## 来源

Stripe Slate 与 Blurple 关系衍生，辅助阶为项目适配值。

## visual-direction-approval 展示话术

这是一套精密、现代、带流动感的深蓝紫科技方向，适合支付科技、基础设施、开发平台和数据产品。代价是整体气质偏冷，不适合自然生活方式、儿童教育和传统文化内容。实现时由深 Slate 承担文字与技术纵深，紫色负责行动，青色只做活跃信号。
