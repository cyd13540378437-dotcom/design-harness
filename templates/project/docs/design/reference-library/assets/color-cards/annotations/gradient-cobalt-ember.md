# 渐变：钴蓝余烬

## 用户可见摘要

深蓝黑底叠加钴蓝冷光与少量琥珀余温，呈现精密仪器般的技术气质。

## 色彩气质

钴蓝、仪器、冷暖、精密。

## 适合的产品语义

- 硬件科技
- 数据平台
- 基础设施
- 工程作品集

## 不适合的产品语义

- 儿童产品
- 自然健康
- 传统文化内容

## 界面落地建议

冷光承担技术纵深，暖光只在对角边缘平衡温度，正文保持稳定暗面。

渐变仅用于画布环境光和低透明面板反射，正文区域、表单、按钮与长内容必须保留稳定纯色底。

## 无障碍与可读性风险

风险等级：medium。

- 正式实现需检查正文、按钮、细线、标签和禁用态。
- 不得仅依靠颜色表达状态或优先级。

## 来源

Yudi AI Lab 项目定制双光源渐变。

## visual-direction-approval 展示话术

这是一套钴蓝冷光与少量琥珀余温并置的精密技术方向，适合硬件科技、数据平台、基础设施和工程作品集。代价是仪器感较强，不适合儿童、自然健康和传统文化内容。实现时冷光承担技术纵深，暖光只在对角边缘平衡温度，正文保持稳定暗面。
