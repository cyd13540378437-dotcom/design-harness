# Design Engineering Module

This directory is the canonical module root for Design Engineering.

Default user-facing module export:

```text
DESIGN_OVERVIEW.md
```

Maintainer and runtime assets:

```text
WORK_ITEMS.md
DELIVERY_EXPORTS.yml
VISUAL_DESIGN.md
project-memory/
reference-library/
reference-images/
outputs/
work-items/
```

Sealed Work Item state, the visual baseline, Project Memory, and current outputs
remain source assets. The overview is compiled from them and is not itself source
of truth.
