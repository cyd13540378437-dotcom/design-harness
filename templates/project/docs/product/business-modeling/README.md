# Business Modeling Module

This directory is the canonical module root for Product Business Modeling.

Default user-facing module export:

```text
BUSINESS_MODEL_OVERVIEW.md
```

Maintainer and runtime assets:

```text
BUSINESS_MODEL_INDEX.md
BUSINESS_MODEL_INDEX.yml
BUSINESS_MODEL_WORK_ITEMS.md
DELIVERY_EXPORTS.yml

model-triggers/
domain-objects/
relationships/
actions/
states/

roadmap/
risks/
downstream-views/
```

Detailed model assets are source of truth. The overview is compiled from them and
is not itself source of truth.
