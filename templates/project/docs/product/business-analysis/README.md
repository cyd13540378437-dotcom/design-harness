# Business Analysis Module

This directory is the canonical module root for Product Business Analysis.

Default user-facing module export:

```text
BUSINESS_DECISION_OVERVIEW.md
```

Maintainer and runtime assets:

```text
BUSINESS_ANALYSIS_INDEX.md
BUSINESS_ANALYSIS_INDEX.yml
BUSINESS_ANALYSIS_WORK_ITEMS.md
DELIVERY_EXPORTS.yml
decision-cases/
decision-network/
evidence/
reviews/
work-items/
```

Decision Cases, the Decision Network, and evidence records are source of truth.
The overview is compiled from module-owned assets and is not itself source of
truth.
